Browser search runs unproxied (Google first, DuckDuckGo HTML fallback in search.functions.ts); only clicked sites are proxied — through Ultraviolet (public/uv/sw.js entry importing the library uv.sw.js, Wisp via bare-mux, set up in ultraviolet.ts), enabled only after a hidden probe page loads through it, with /api/public/p as the fallback.
browserDestination unwraps /uv/service/ and /api/public/p addresses so proxied URLs are never re-wrapped; /uv/service/* falls back to the edge proxy when the worker is not in control; setup removes any non-current worker, and a hosting error page in the frame turns Ultraviolet off for the session.
Proxy compatibility preserves incoming browser identity, translates upstream referrers and leaves consent intact instead of spoofing browser globals or rotating fingerprints; direct browser opening is the fallback for unsupported website checks.
DuckDuckGo policy is rechecked against the cookie-authenticated account on the server, including image requests and upstream preference cookies; client controls cannot grant permission to disable Safe Search.
The Browser owns its navigation stack and accepts only same-origin messages from its current iframe; resource property setters and mutation handling keep dynamic images inside the proxy.
Chat media is chunk-uploaded before sending and linked in sendMessage, which re-checks the per-message rank allowance on the server; storage chunks are freed through removeChunks on owner hard delete, manual removal and abandoned-upload cleanup.
